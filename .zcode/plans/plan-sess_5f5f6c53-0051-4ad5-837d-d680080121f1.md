## 计划:管理端换商标 + 打印任务接入打印机

### 一、左上角商标换成小程序同款
1. 复制 `miniapp/src/static/images/brand/logo-glyph.png`(圆环+相框+山的墨色 glyph)→ `desktop-admin/src/assets/images/logo-glyph.png`。
2. `src/App.vue` 侧栏 `.brand`:把 CSS 画的 `brand-lens` 圆圈镜头替换为 `<img class="brand-logo">`(34px)。
3. `src/modules/auth/Index.vue` 登录页 `login-brand` 同样替换。
4. `src/style.css` 新增 `.brand-logo` 样式,移除不再使用的 `.brand-lens` 规则。

### 二、打印任务页新增「连接打印机」与直印
架构:Electron 主进程具备系统打印能力(`webContents.getPrintersAsync()` + 隐藏窗口 `webContents.print()`),渲染层经 contextBridge 调用。

1. 新建 `electron/print.cjs` 并在 `main.cjs` 注册:
   - `list-printers` IPC:返回系统打印机列表(名称、状态、是否默认)。
   - `print-photos` IPC:入参 `{ html, deviceName, copies }`;主进程建隐藏 BrowserWindow,`loadURL(data:text/html…)` 载入打印版面,调用 `webContents.print({ printBackground: true, deviceName, copies, silent })`——已选打印机时静默直印,未选时 `silent:false` 弹出系统打印对话框让用户选。
2. `preload.cjs` 暴露 `listPrinters()` / `printPhotos()`,与现有 `studio` 桥接口风格一致。
3. `src/modules/printing/Index.vue`:
   - 顶部工具条:「连接打印机」按钮(点击后列出系统打印机,下拉可选择目标打印机并显示状态/默认标记,可刷新)。
   - 每个待打印订单新增「打印照片」操作:取该订单已选照片(没有则全部)→ 用现有 `photoUrl()` 拉图并转成 dataURL → 生成打印 HTML(页眉含订单号/规格,每页一张照片)→ 调 `printPhotos` 送打印机;打印成功后提示,可顺手标记「打印中」。
   - 浏览器环境(非 Electron)运行时按钮给出提示「请通过管理端客户端使用打印」。
   - 更新页面副标题文案(原「打印操作请在打印机软件完成」已不适用)。
4. 验证:`npx vite build`;跑 `electron --smoke-test`(项目已有该开关)确认主进程不崩。

注:打印照片走本机系统打印机驱动,无需额外依赖;份数取自订单 `print.quantity`,规格(尺寸/纸张)打印在页眉供对照。
