你现在是一名资深全栈开发工程师，请直接在我的 Windows 电脑上创建并开发一个“校园照相馆微信服务系统”。不要只告诉我步骤，要实际创建文件夹、编写代码、安装依赖、运行检查并修复错误。

一、项目目录

请在 D 盘新建项目根目录：

D:\CampusPhotoStudio

如果目录已经存在，先检查里面的文件，不要直接删除或覆盖已有内容。

项目采用 monorepo 结构：

D:\CampusPhotoStudio
├─ miniapp             微信小程序顾客端
├─ desktop-admin       店内电脑管理端
├─ cloudfunctions      微信云开发云函数
├─ shared              公共类型、常量、校验规则
├─ docs                需求、数据库和部署文档
├─ README.md
└─ .gitignore

所有业务模块必须拆分。禁止把全部页面、接口、数据库操作和工具函数写在同一个文件中。

“一个功能一个文件”的具体要求：

1. 每个页面使用独立文件或独立目录。
2. 每个业务模块使用独立 service 文件。
3. 每个云函数使用独立目录。
4. 数据类型、常量、校验规则和工具函数分别存放。
5. UI组件拆分为独立组件。
6. 单个业务文件尽量不超过300行。
7. 禁止出现一个几千行的 App.vue、index.vue 或 service.js。
8. 公共逻辑必须复用，不能在多个页面复制粘贴。

二、系统定位

系统主要服务校内大学生和校园照相馆，重点解决以下问题：

1. 学生预约证件照和写真时需要反复微信沟通。
2. 学生不清楚考试报名照的尺寸、背景色和文件要求。
3. 冲印照片需要到店传文件，效率较低。
4. 店员容易遗漏预约、修图、打印和取件任务。
5. 顾客经常询问订单是否完成。
6. 写真和毕业照选片容易出现照片编号混乱。
7. 高清照片不应长期全部保存在云端。

三、技术方案

1. 微信小程序端：

   * Uni-app
   * Vue 3
   * TypeScript
   * Pinia
   * 使用微信小程序作为主要编译目标

2. 店内电脑管理端：

   * Electron
   * Vue 3
   * TypeScript
   * Vite
   * Pinia
   * Element Plus
   * 使用 SQLite 保存必要的本地配置、同步状态和本地文件索引
   * 原始高清照片保存在店内电脑，不存入数据库

3. 云端：

   * 微信云开发 CloudBase
   * 云数据库
   * 云存储
   * 云函数
   * 开发阶段提供 mock 数据模式，没有微信 AppID 和云环境ID时也能运行和预览

4. 工程要求：

   * 使用 npm
   * 配置 ESLint 和 Prettier
   * 提供 .env.example
   * 不得在代码中写入真实密钥、AppID或密码
   * 前后端共享 TypeScript 类型
   * 所有金额统一使用“分”存储，界面显示时转换成“元”
   * 所有时间统一保存标准时间，界面按中国时区显示
   * 使用中文界面和中文注释，但变量、函数和文件名使用规范英文

每个云函数使用独立目录，不要合并成一个巨大云函数。

八、界面设计要求

整体风格面向大学生群体：

* 明亮、干净、年轻、有摄影氛围
* 主色使用温暖奶油白搭配深灰，可使用少量橙色或胶片红点缀
* 避免过度科技蓝
* 避免廉价渐变和复杂发光效果
* 小程序首页突出证件照、冲印、毕业季和订单查询
* 页面留白合理
* 按钮和文字适合手机触控
* 后台突出效率和信息层级
* 所有页面提供加载、空数据、错误和成功状态
* 不使用来源不明的受版权保护图片
* 演示图片使用本地占位图或明确可替换素材

九、安全与隐私要求

照片和手机号属于敏感数据，必须做到：

* 手机号脱敏
* 管理员权限校验
* 上传文件类型和大小校验
* 云端文件设置有效期
* 禁止把密钥写入Git
* 操作日志记录
* 数据导出需要管理员权限
* 禁止使用任意用户输入拼接本地文件路径
* 防止路径穿越
* 不允许自动删除本地原图
* 删除和覆盖文件前必须确认具体目标
* README中说明数据备份方案
* 小程序提供隐私政策入口
* 开发演示数据不得包含真实学生姓名、手机号和照片
