# 微信开发者工具导入

1. 在根目录执行 npm.cmd run build:mp。
2. 微信开发者工具导入 D:\夏洁校内照相馆系统\miniapp\dist\build\mp-weixin。
3. 无AppID时可使用工具支持的测试/游客预览能力；以当前工具许可为准。无需AppID的可验证演示入口是 H5 http://127.0.0.1:5174。
4. 本机 Mock 地址为 http://127.0.0.1:8787/api。开发工具测试时关闭请求域名校验；真机里的127.0.0.1指向手机本身，不能连接电脑。本服务默认仅监听回环地址，未开放局域网。
5. 真机或正式发布须填写自己申请的AppID、配置云环境与合法域名，切勿编造。当前未实际启动微信开发者工具或真机验收。
6. AppID填写到 miniapp/src/manifest.json 的 mp-weixin.appid；复制 miniapp/.env.example 为 .env.local 后填写环境。正式云模式必须先部署全部函数、初始化数据并验证云文件与桌面鉴权，不能仅改开关就上线。

已验证产物：H5 与 mp-weixin 编译成功。构建提示未配置AppID导致统计不可用属预期；本项目不依赖uni统计。
