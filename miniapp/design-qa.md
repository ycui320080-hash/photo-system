# miniapp 首页设计验收

## 依据

- 用户提供的小程序摄影工作室参考图与本轮文字规范
- 实现截图：`miniapp/screenshots/home-375-first-screen.png`
- 完整长图：`miniapp/screenshots/home-375-full.png`

## 结果

| 检查项 | 结果 | 证据 |
|---|---|---|
| 顶部品牌 | 通过 | 品牌栏中“一帧照相馆”仅出现一次；高度 68px；右侧预留微信胶囊区域 |
| 主视觉 | 通过 | 270px；一张校园主图与一张小拍立得；标题固定两行 |
| 主要服务 | 通过 | 两个按钮等宽、46px 高、`nowrap` |
| 快捷入口 | 通过 | 2×2、96px 高；统一 1.8px 圆角线性 SVG 图标 |
| 推荐内容 | 通过 | 证件照横向卡片；毕业写真横向滑动卡片 |
| 一帧作品 | 通过 | 8 个不同场景；首页 15 个照片槽位无重复素材 ID |
| 店铺信息 | 通过 | 地址为“一食堂楼下商铺103”；联系与位置均有反馈 |
| TabBar | 通过 | 五项统一线性 SVG；22px；当前项砖红；无 Logo 与人物缩略图 |
| 二维码 | 通过 | miniapp 源码未发现“二维码”“扫码取件”或 QR 组件引用 |
| 375px | 通过 | 文档宽度与滚动宽度均为 375px；无横向溢出 |
| 390px | 通过 | 文档宽度与滚动宽度均为 390px；无横向溢出 |
| 414px | 通过 | 文档宽度与滚动宽度均为 414px；图片使用 `aspectFill` / `background-size: cover`，不拉伸 |
| 底部安全区 | 通过 | 主内容底部保留约 92px；TabBar 单独适配安全区 |

## 构建

- `npm run check`：通过
- `npm run build:mp -w miniapp`：通过
- uni-app 构建仍输出项目既有的 Sass legacy API 和其他页面 `small` 选择器警告，不影响本次构建产物
