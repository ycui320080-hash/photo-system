# 小程序图片资源说明

品牌资产位于 `brand/`。`logo-original.jpg`、`logo-full.png`、`logo-mark.png` 为受保护素材，不得删除或覆盖；首页使用 `logo-mark.png`。

首页临时摄影素材位于 `home/`，并由 `assets-manifest.ts` 记录用途与替换要求。当前素材均为无校名、无校徽、无其他品牌水印的中性中国大学摄影演示图。

正式上线前请店主替换以下照片，并保持文件用途互不混用：

- 安徽工程大学校园主视觉和树荫道路
- 两组不同的单人毕业写真
- 宿舍多人合照
- 校园跟拍摄影师工作照
- 班级集体照
- 女性与男性证件照样片
- 门店拍立得冲印场景
- 门店照片墙或纸质照片成品

`campus/`、`graduation/`、`packages/`、`placeholders/` 中的 SVG 是早期遗留占位资源，当前首页不再引用；为避免误删用户已有文件，本次保留它们。
